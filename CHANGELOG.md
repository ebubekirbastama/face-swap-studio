# Changelog

All notable changes to this project will be documented here.

## 1.0.0 - 2026-08-07

- Initial open-source repository structure.
- Responsive Tkinter GUI.
- CPU-based InsightFace / ONNX Runtime processing.
- Source, target and result previews.
- Single-face or all-face replacement option.
- Original, 1080p and 4K export presets.
- Unicode-safe Windows image I/O.
- Background model loading and processing.
- Runtime logging.
- Safer temporary-file model download workflow.
- Explicit third-party model licensing notice.
