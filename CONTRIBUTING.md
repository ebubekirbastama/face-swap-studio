# Contributing

Thank you for considering a contribution.

## Workflow

1. Fork the repository.
2. Create a focused feature/fix branch.
3. Keep changes small and documented.
4. Run `ruff check .` and `python -m compileall src main.py`.
5. Do not commit model binaries, personal photographs, generated face-swap outputs, secrets, or local logs.
6. Open a pull request explaining the problem and the change.

## Scope

Good contributions include bug fixes, UI improvements, accessibility, packaging,
performance improvements, tests and documentation.

Contributions designed primarily for deceptive impersonation, evading provenance,
non-consensual imagery or other harmful use cases are outside this project's scope.
